# Boiler Control Web App

React + Ant Design + Tailwind CSS web application for Boiler Control System.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/pages/` - Page components (Login, Dashboard, etc.)
- `src/components/` - Reusable components (MainLayout, ProtectedRoute, etc.)
- `src/services/` - API client and external service integrations
- `src/context/` - React context for state management
- `src/hooks/` - Custom React hooks
- `src/utils/` - Utility functions
