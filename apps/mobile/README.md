# Boiler Control Mobile App

React Native + Expo mobile application for Boiler Control System using NativeBase and NativeWind.

## Development

```bash
npm install
npm start
```

Then use:
- `npm run ios` - Run on iOS
- `npm run android` - Run on Android
- `npm run web` - Run on Web

## Build

```bash
npm run build
```

## Structure

- `src/screens/` - Screen components (Login, Dashboard, etc.)
- `src/components/` - Reusable components
- `src/services/` - API client
- `src/context/` - React context for state management
- `src/hooks/` - Custom React hooks
- `src/utils/` - Utility functions
